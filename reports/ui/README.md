# 오늘 화면 2안 시범 구현

- 실제 앱: http://127.0.0.1:4173/
- 작업 진행 중 시안 미리보기: http://127.0.0.1:4173/?preview=today
- 미리보기는 별도 메모리 상태만 사용하며 기존 브라우저 저장 데이터를 읽거나 덮어쓰지 않습니다. 새로고침하면 예시가 초기화됩니다.

## 적용

- Mona10x12 Regular/Bold: 제목, 일정, 버튼과 시간 안내.
- MemomentKkukkukk Regular: 여유시간 항목과 수치.
- Kyobo Handwriting 2025 lyb: 일정 시작·종료 시각.
- 정원 배경, 토끼 보더, 종이 텍스처, 노트북·식사·커피·운동 아이콘 등 기존 에셋 사용.
- 시간 막대는 실제 시작부터 예상 종료까지의 경과를 표시합니다. 기록된 집중 구간만 파란 그라데이션으로 표시하며, 정지 구간은 #F5EBDC를 유지합니다. 초과 시 커서는 끝에 머물고 초과 시간을 표시합니다.
- 과거 집중 합계만 있는 기존 실행에는 없는 구간 정보를 만들어 넣지 않습니다. 새로 측정된 구간부터 궤적이 표시됩니다.
- 테스트 시계 제거. 다른 작업 전환, 미완료 종료, 완료, 기록 확인, 추가, 여유시간 접기/펼치기 연결. 나의 루틴은 일정 아래에서 펼쳐볼 수 있습니다.

## 검증

- Node 테스트 58개 통과: 기존 일정 로직 53개 및 집중 구간·초과·휴식·미리보기 저장 격리·에셋 경로 검사.
- 브라우저: 집중 타이머 정지/재개, 정지 중 시간 유지, 통계 접기/펼치기, 전환/완료/미완료/알림/추가 연결. 미완료 종료를 저장한 뒤 남은 작업 재배치와 다음 상태 전환 확인.
- 320×874, 402×874, 1200×900 화면 확인. 작은 모바일에서 가로 넘침과 누락 이미지 없음. 브라우저 오류 로그 없음.
- 스크린샷: `today_mobile.png`, `today_small_mobile.png`, `today_desktop.png`.
